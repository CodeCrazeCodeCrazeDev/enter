## 1. Prioritization Framework & Scoring Methodology

Engineering initiatives are evaluated using a strict **Expected Return-on-Investment Score ($R_{ROI}$)**:

$$R_{ROI} = \frac{\Delta \text{Intelligence} + \Delta \text{Reliability} + \Delta \text{Scalability}}{\text{Engineering Effort (Person-Weeks)} \times (1 + \text{Architectural Complexity Risk})}$$
