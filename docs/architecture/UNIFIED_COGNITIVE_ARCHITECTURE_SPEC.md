# Unified Cognitive Architecture Specification

## Executive Summary
This document specifies the unified 4-layer cognitive operating system taxonomy for APODEX / AI-EOS / AEAN / Research OS.

## 4-Layer Taxonomy
1. **Layer 1: Scientific Research OS Subsystem**
   - Autonomous science loop, hypothesis registration, power analysis, and statistical validation (DSR, White's Reality Check).
2. **Layer 2: Entrepreneurial Intelligence & Decision Subsystem (EIOS / EOS)**
   - EIOS Kernel active inference sensing, Expected Free Energy minimization, and EOS 14-layer computational engine.
3. **Layer 3: Cognitive Multi-Agent & Execution Subsystem (AEAN)**
   - HiveMind token bidding registry, multi-agent Shepherd routing, and swarm consensus orchestration.
4. **Layer 4: World Model & Platform Runtime Subsystem (APODEX)**
   - Continuous multi-graph world model (E-K-C-T-U subgraphs), belief updates, and protocol execution.

## Inter-Layer Interfaces
- Active inference state handoffs flow downstream from Layer 1 Research OS hypotheses to Layer 2 EIOS Kernel & EOS Engine, driving Layer 3 AEAN multi-agent strategy execution, and recording persistent state in Layer 4 APODEX WorldModel.
