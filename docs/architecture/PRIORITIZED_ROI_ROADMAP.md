# Prioritized ROI Roadmap (AEAN / EIOS / EOS / APODEX / Research OS)

This roadmap prioritizes engineering efforts based on Expected Return on Effort (EROE), calculated as:
$$\text{EROE} = \frac{\text{Capability Delta} \times \text{Reliability Delta}}{\text{Implementation Complexity}}$$

---

## Phase Priority Matrix

| Rank | Milestone / Focus Area | Target Layers | Estimated ROI | Key Deliverables | Risk Level |
|---|---|---|---|---|---|
| **1** | **Unified Cross-Layer Active Inference Bridge** | Layer 1 <-> 2 <-> 3 <-> 4 | **10x** | `ResearchToSystemBridge`, cross-layer EFE propagation, closed-loop hypothesis handoff | Low |
| **2** | **Hawkes Non-Gaussian Code Refactoring Engine** | Layer 3 (AEAN) | **8.5x** | AST depth verification, automated AST rewrite verification, zero-crash code evolution | Medium |
| **3** | **MAP-Elites Island Workflow Genetic Optimizer** | Layer 3 (AEAN) | **7.2x** | Population diversity preservation, dynamic agent prompt/workflow mutation | Medium |
| **4** | **Causal Bayesian World Model & Do-Calculus Engine** | Layer 4 (APODEX) | **6.8x** | Graph-based causal interventions, counterfactual reasoning, Bayesian belief updates | High |
| **5** | **Autonomous Entrepreneurial Capital Allocation Engine** | Layer 2 (EOS) | **5.5x** | Real-time unit economics simulation, automated SLA/budget enforcement | Medium |
