## 2. Explicit Flow Contracts

We formalize how data, logic, and state transitions propagate through our Unified Cognitive Operating System.

### 2.1 Information & Causal Event Flow
1. **Observation**: Active runtime worker agents publish `ObservationEvent` payloads upon action execution.
2. **Assimilation**: The Cognitive System Controller captures the event, triggers entity-resolution pipelines, and asserts new relation nodes to the Causal World Graph.
3. **Estimation**: The Causal Inference Engine performs backdoor criterion adjustments over newly registered causal links to update deterministic exogenous variables.

### 2.2 Memory Consolidation Flow
* **Working Memory**: Local execution variables, thread states, and raw tool buffers are held strictly in thread-local memory.
* **Episodic Persistence**: Complete trace steps are transactionally committed to SQLite at the end of each task loop turn.
* **Semantic Consolidation**: Asynchronously, background memory sweeper daemons select historical episodes, run token-bounded summaries, extract fact statements, and commit them as persistent Semantic nodes or Procedural Skills (with standard Jaccard indexing).

### 2.3 Planning & Evaluation Flow
* **Goal-Conditioned decomposition**: High-level venture or discovery targets are recursively decomposed into primitive execution plans using HTN operators.
* **MCTS Optimization**: Subtasks are evaluated by simulating outcomes via the Predictive World Model and scoring trajectories using UCT selection metrics.
* **Non-Bypassable Verification**: After each primitive action, the output is scored against the acceptance criteria. If a step fails, the system triggers real-time graph edit corrective actions (ADD_STEP, REPLACE_STEP, DELETE_STEP) rather than failing the entire run.

### 2.4 Governance & Safety Flow
* **Tenancy Isolation**: All executed code and scraper routines are bounded inside isolated Docker containers with memory/CPU caps.
* **Suitability Gates**: No prompt, configuration, or code generated by self-improvement loops is promoted to active production unless it scores $\ge 1.05x$ over previous stable baselines in shadow rollouts.
* **Immutable Core**: Safety parameters, API resource limits, and financial validation scopes are protected from code self-modification layers.

## 3. Interface Contracts & API Specifications

To prevent circular imports, all major subsystems communicate using structured protocols.

### 3.1 Causal Inference Engine Interface
```python
class ICausalInferenceEngine(ABC):
    @abstractmethod
    def assert_causal_link(self, cause_id: str, effect_id: str, coefficient: float) -> None:
        """Asserts a causal relationship in the Structural Causal Model graph."""
        pass

    @abstractmethod
    def evaluate_counterfactual(self, scenario_id: str, overrides: dict) -> dict:
        """Simulates a hypothetical scenario by intervening on exogenous parents."""
        pass
```

### 3.2 Strategy Planner Interface
```python
class IStrategyPlanner(ABC):
    @abstractmethod
    async def generate_decomposition_plan(self, goal: str, context: dict) -> List[dict]:
        """Decomposes a compound goal into a sorted list of primitive steps."""
        pass

    @abstractmethod
    async def evaluate_expected_utility(self, steps: List[dict]) -> float:
        """Computes expected utility using active inference and pragmatic value."""
        pass
```

### 3.3 Memory Consolidation Interface
```python
class IMemoryConsolidation(ABC):
    @abstractmethod
    async def consolidate_episodic_traces(self, max_tokens: int) -> dict:
        """Sweeps SQLite episodes and distills them into Semantic Memory facts."""
        pass

    @abstractmethod
    async def apply_forgetting_curve(self, current_time: float) -> int:
        """Applies Ebbinghaus decay formulas to adjust retention strength."""
        pass
```
