# Deliverable 5 — ROI Roadmap

## 1. Prioritization Formula

The Return on Investment (ROI) score is calculated as:

$$\text{ROI Score} = \frac{\text{Expected Capability Gain} \times \text{Architectural Leverage} \times \text{Probability of Success}}{\text{Implementation Cost} \times \text{Complexity} \times \text{Risk}}$$

Where each parameter is scored between 1 (lowest) and 5 (highest).
