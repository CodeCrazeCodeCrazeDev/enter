## ROI Prioritization Framework

Projects are ranked by expected Return on Engineering Effort ($\text{ROI}$):

$$\text{ROI} = \frac{\Delta \text{Capability} + \Delta \text{Reliability} + \Delta \text{Scalability}}{\text{Engineering Complexity} \cdot \text{Risk}}$$
