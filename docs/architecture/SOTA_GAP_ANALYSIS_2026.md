## Detailed Gap Analysis & Mitigations

### 1. Planning Under Long-Horizon Uncertainty
- **SOTA Gap:** Standard agents lose context coherence past 50 steps or fail when tool outputs deviate from expectations.
- **APODEX Solution:** Active Inference Expected Free Energy (EFE) minimization explicitly calculates epistemic uncertainty vs. instrumental value, dynamically re-planning DAG execution without context fragmentation.

### 2. Code Refactoring & Software Engineering Automation
- **SOTA Gap:** Code refactoring agents often introduce recursive stack overflows or break hidden assumptions in legacy code.
- **APODEX Solution:** AST call-graph recursion depth checking combined with Hawkes process self-excitation stability filters prevents unstable recursive code proposals before execution.

### 3. Cross-Domain Transferable Knowledge
- **SOTA Gap:** Multi-agent systems lack a mechanism to convert empirical trial outcomes into domain-agnostic transferable engineering principles.
- **APODEX Solution:** Research OS Literature Extractor continuously mines cross-domain literature (600+ paper corpus) and indexes actionable engineering principles across Layer 2 and Layer 3 modules.
