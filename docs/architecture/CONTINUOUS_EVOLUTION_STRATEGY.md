## 2. Regression Prevention & Quality Standards
1. **Automated Continuous Integration:** Every proposed modification must pass full pytest execution with zero failures across unit, integration, and cognitive test suites.
2. **Empirical Evidence Requirement:** Any algorithmic or prompt mutation must demonstrate statistically significant performance gains (e.g. +EFE delta, reduced token budget) prior to promotion.
3. **Complexity Accounting:** Code modifications must not exceed predefined execution memory and computational time budgets.
