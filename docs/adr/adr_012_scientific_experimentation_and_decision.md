# ADR 012: Hypothesis Generation, Scientific Experimentation, and Decision Intelligence

## Status
Approved

## Context
Legacy hypotheses are updated and promoted via flat un-versioned properties, introducing cascading epistemic risk where falsified foundational assumptions fail to update downstream strategic policies.

## Decision
We establish:
1. A Recursive Bayesian Belief Engine using conjugate Beta-Binomial update rules over a structured EKG.
2. A sequential active inference planner implementing Monte Carlo Tree Search (MCTS) exploration-exploitation trees to minimize Expected Free Energy (EFE).

## Consequences
- **Pros:**
  - Guarantees exact, safe belief propagation across the dependency DAG.
  - Unlocks long-horizon, multi-step strategic planning horizons.
- **Cons:**
  - Higher database indexing and write transaction volumes.
