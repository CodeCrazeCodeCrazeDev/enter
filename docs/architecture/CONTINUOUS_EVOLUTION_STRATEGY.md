## 2. Regression Benchmarking & Statistical Validation Framework

To guarantee that continuous updates do not degrade system stability or performance, all self-improvements must pass through a 3-tier statistical gate:

1. **Automated Unit & Integration Regression Suite**:
   * Every code change must maintain 100% pass rate across all system tests (`PYTHONPATH=.:AgentHarness python3 -m pytest -q --import-mode=importlib`).
2. **Welch's Two-Sample t-Test Validation**:
   * Performance gains across execution speed, accuracy, or context compression must satisfy $p < 0.01$:
     $$t = \frac{\bar{X}_1 - \bar{X}_2}{\sqrt{\frac{s_1^2}{N_1} + \frac{s_2^2}{N_2}}}$$
3. **Deflated Sharpe Ratio (DSR) & Multiple Testing Controls**:
   * Prevents backtest overfitting and false discoveries when generating new autonomous skills or strategies.

## 3. Institutional Governance, Safety & Approval Gateways

Continuous evolution operates under strict institutional governance guardrails:

* **Tier 1: Read-Only Research & Hypothesis Sensing**: Unrestricted autonomous exploration in Layer 1 & Layer 2.
* **Tier 2: Non-State Executions & Simulations**: Autonomous execution permitted within isolated sandbox environments in Layer 3.
* **Tier 3: State-Mutating Operational Actions**: Requires verification against pre-trade compliance policies, capital allocation limits, and tiered approval gateways in Layer 4 before committing to the world graph.
* **Automated Rollback Safeguard**: If post-deployment telemetry detects an anomaly (e.g., drawdown exceeding threshold $\delta$ or unexpected error spikes), the platform triggers an automatic state rollback to the last verified checkpoint.
